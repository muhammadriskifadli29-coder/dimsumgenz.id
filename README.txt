DIMSUM GEN Z — WEBSITE LANDING PAGE

Isi folder:
- index.html : struktur dan konten website
- style.css  : tampilan, warna, layout responsif
- script.js  : navigasi mobile, filter menu, dan tautan WhatsApp
- assets/    : foto produk hasil crop dari poster yang diberikan

Cara menjalankan:
1. Simpan semua file dalam satu folder dengan struktur yang sama.
2. Buka index.html di browser.
3. Untuk publikasi, unggah seluruh isi folder ke hosting statis (misalnya GitHub Pages atau Netlify).

Catatan penyesuaian:
- Harga mengikuti poster: Original Rp15.000, Mentai Rp25.000, Mozarella Rp20.000.
- WhatsApp menggunakan nomor 0882 1177 0143.
- Lokasi ditampilkan sebagai Mauk, Kabupaten Tangerang karena alamat jalan lengkap belum diberikan.
- Filter Goreng dan Paket disediakan; saat ini kartu produk yang diketahui masuk kategori Kukus. Ubah atribut data-category di index.html jika kategori sebenarnya berbeda.
- Klaim halal ditulis sebagai "mengutamakan bahan halal", bukan klaim sertifikasi.
